# 🚢 Cómo Jugar Batalla Naval Online

## Para Jugadores Nuevos

### ✅ Requisitos
- Tener Java instalado ([Descargar aquí](https://www.java.com/es/download/))
- Conexión a Internet

### 🎮 Cómo Conectarse (3 pasos)

**OPCIÓN 1 - La Más Fácil:**

1. Descarga el archivo `JUGAR.bat` 
2. Haz doble clic en `JUGAR.bat`
3. ¡Listo! El juego se abrirá automáticamente

---

**OPCIÓN 2 - Manual:**

1. Descarga el archivo `battleship-client-jar-with-dependencies.jar`

2. Abre PowerShell o CMD en la carpeta donde descargaste el archivo

3. Ejecuta:
   ```
   java -jar battleship-client-jar-with-dependencies.jar 68.211.112.149 8080
   ```

---

## 📝 Al Iniciar el Juego

1. **Se abrirá una ventana** pidiendo tu nombre
2. **Escribe tu nombre** (mínimo 2 caracteres)
3. **Haz clic en OK**
4. **Espera** a que aparezca el mensaje "✓ Conectado al servidor"

## 🎯 Cómo Jugar

### Paso 1: Colocar Barcos
- Haz clic en TU TABLERO (izquierdo) para colocar tus 5 barcos
- Usa el botón "🔄" para cambiar entre horizontal/vertical
- Cuando termines, haz clic en "✅ ¡LISTO PARA JUGAR!"

### Paso 2: Esperar al Oponente
- El juego comienza cuando ambos jugadores estén listos

### Paso 3: Atacar
- Cuando sea tu turno, haz clic en el TABLERO ENEMIGO (derecho)
- Verás si acertaste (🔥 IMPACTO) o fallaste (💧 AGUA)
- El juego termina cuando hundes todos los barcos del enemigo

## ⚠️ Problemas Comunes

**"Error: Unable to access jarfile"**
- Verifica que el archivo .jar esté en la misma carpeta donde ejecutas el comando

**"Connection failed"**
- Verifica tu conexión a Internet
- Asegúrate de que el servidor esté activo

**"Java no se reconoce como comando"**
- Necesitas instalar Java: https://www.java.com/es/download/
