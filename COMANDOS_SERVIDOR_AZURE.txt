COMANDO PARA EJECUTAR SERVIDOR EN AZURE VM CON CONTRASEÑA
===========================================================

🔥 SERVIDOR OPTIMIZADO CON:
  - Timeouts de 120s para estabilidad
  - Env\u00edos as\u00edncronos evitan bloqueos  
  - Heartbeat cada 5s detecta problemas r\u00e1pido

Opción 1: Comando SSH directo (pedirá contraseña)
--------------------------------------------------
ssh azureuser@68.211.112.149 "cd /home/azureuser && nohup java -jar battleship-server-jar-with-dependencies.jar > server.log 2>&1 &"

Opción 2: Con sshpass (si tienes la contraseña guardada)
---------------------------------------------------------
sshpass -p "TU_CONTRASEÑA" ssh azureuser@68.211.112.149 "cd /home/azureuser && nohup java -jar battleship-server-jar-with-dependencies.jar > server.log 2>&1 &"

Opción 3: Script PowerShell (Windows)
--------------------------------------
.\run-server-azure.ps1 -User azureuser -Host 68.211.112.149 -Password "TU_CONTRASEÑA"

Opción 4: Script Bash (Linux/Mac)
----------------------------------
./run-server-azure.sh azureuser 68.211.112.149 "TU_CONTRASEÑA"

COMANDOS ÚTILES DESPUÉS DE INICIAR
====================================

Ver logs en tiempo real:
ssh azureuser@68.211.112.149 "tail -f /home/azureuser/server.log"

Verificar que el servidor está corriendo:
ssh azureuser@68.211.112.149 "ps aux | grep battleship-server"

Detener el servidor:
ssh azureuser@68.211.112.149 "pkill -f battleship-server"

Reiniciar el servidor:
ssh azureuser@68.211.112.149 "pkill -f battleship-server; cd /home/azureuser && nohup java -jar battleship-server-jar-with-dependencies.jar > server.log 2>&1 &"

CONECTAR CLIENTE A SERVIDOR REMOTO
===================================

Modificar el cliente para conectarse a la VM:
1. En el cliente Java, cambiar: ws://localhost:8080/battleship
   Por: ws://68.211.112.149:8080/battleship

O editar GameWindow.java línea ~36:
Cambiar: String websocketUrl = "ws://localhost:8080/battleship";
Por: String websocketUrl = "ws://68.211.112.149:8080/battleship";

Luego recompilar:
mvn clean install -DskipTests
